# BME280 / BMP280 / SHT31 - датчики тиску, вологості та температури

## Purpose

Лінійка прецизійних I2C/SPI сенсорів Bosch + Sensirion for метеостанцій, альтиметрів, клімат-контролю та вуличних IoT-вузлів. BME280: температура + вологість + тиск (все in одному). BMP280: температура + тиск, without вологості (дешевший). SHT31: еталонна вологість/температура from Sensirion, вища точність вологості. Інтерфейс - I2C (адреси 0x76/0x77 in Bosch, 0x44/0x45 in Sensirion), живлення 1.7-3.6V, сон - мікроампери.

## Характеристики

| Параметр | BME280 | BMP280 | SHT31-DIS |
| --- | --- | --- | --- |
| Температура | −40…+85 °C, ±1 °C | −40…+85 °C, ±1 °C | −40…+125 °C, ±0.3 °C |
| Вологість | 0…100 %, ±3 % | Немає | 0…100 %, ±2 % |
| Тиск | 300…1100 гПа, ±1 гПа | 300…1100 гПа, ±1 гПа | Немає |
| Інтерфейс | I2C + SPI | I2C + SPI | I2C |
| I2C-адреси | 0x76 (SDO→GND) / 0x77 (SDO→VCC) | 0x76 / 0x77 (аналогічно) | 0x44 / 0x45 (ADDR) |
| Живлення | 1.8-3.6 in (модулі GY-BME280 мають LDO → 3.3-5 in) | Так само | 2.4-5.5 in |
| Струм | ~3.6 мкА @1 Гц | ~2.7 мкА @1 Гц | ~1.5 мА вимір / 2 мкА сон |
| Особливість | Компенсація via калібрувальні регістри | Дешевший, той же тиск | Нагрівач проти конденсату |

> Увага: китайські модулі with маркуванням «BMP280» інколи реально BME280 and навпаки. Перевіряти ID регістра (`chip_id`: 0x60 = BME280, 0x58 = BMP280) або наявність вологості in даних.

## Розпіновка

| Пін модуля GY-BME/BMP280 | Призначення | Примітка |
| --- | --- | --- |
| VIN/VCC | Живлення 3.3 in | Модулі with LDO терплять 5 in, але ліпше 3.3 in |
| GND | Земля | Спільний GND |
| SCL | I2C clock | До GPIO22 (стандарт) + pull-up |
| SDA | I2C data | До GPIO21 (стандарт) + pull-up |
| SDO | Вибір адреси | GND → 0x76, VCC → 0x77 (залишений висячим = 0x76 on більшості модулів) |
| CSB | Chip select SPI | in I2C-режимі підтягнути до VCC; in SPI - до GPIO |
| SDI/SDO (SPI) | MOSI/MISO | Тільки for SPI-режиму |

SHT31: VIN, GND, SCL, SDA, ADDR (GND → 0x44, VCC → 0x45), ALERT (програмований поріг, можна not підключати).

## Схема підключення

| ESP32 | module (I2C) | Примітка |
| --- | --- | --- |
| 3V3 | VIN | Живлення 3.3 in |
| GND | GND | Спільна земля |
| GPIO22 | SCL | Апаратний I2C0 SCL, pull-up 4.7 кОм (часто вже on модулі) |
| GPIO21 | SDA | Апаратний I2C0 SDA, pull-up 4.7 кОм |
| GND / 3V3 | SDO | GND → 0x76 (типово), 3V3 → 0x77 (якщо конфлікт адрес) |
| 3V3 | CSB | Обов'язково до VCC in I2C-режимі |

SPI-варіант BME280 (швидше опитування, окремий CS on кожен сенсор): SCL→SCK (GPIO18), SDA/SDI→MOSI (GPIO23), SDO→MISO (GPIO19), CSB→CS (GPIO5). Див. [[04-Interfaces/02-SPI|SPI]].

## code ESP-IDF

```c
#include "bme280.h"  // esp-idf-lib або Bosch API
#include "driver/i2c.h"
#include "esp_log.h"

#define I2C_PORT I2C_NUM_0
#define BME_ADDR 0x76

void app_main(void)
{
    i2c_config_t cfg = {
        .mode = I2C_MODE_MASTER,
        .sda_io_num = GPIO_NUM_21,
        .scl_io_num = GPIO_NUM_22,
        .sda_pullup_en = GPIO_PULLUP_ENABLE,
        .scl_pullup_en = GPIO_PULLUP_ENABLE,
        .master.clk_speed = 100000,
    };
    i2c_param_config(I2C_PORT, &cfg);
    i2c_driver_install(I2C_PORT, cfg.mode, 0, 0, 0);

    bme280_handle_t dev;
    bme280_init(&dev, I2C_PORT, BME_ADDR);
    for (;;) {
        float t = 0, h = 0, p = 0;
        bme280_read(&dev, &t, &p, &h);
        ESP_LOGI("bme", "T=%.2f C  P=%.1f hPa  H=%.1f %%", t, p, h);
        vTaskDelay(pdMS_TO_TICKS(2000));
    }
}
```

## code Arduino

```cpp
#include <Wire.h>
#include <Adafruit_BME280.h>
#include <Adafruit_SHT31.h>

Adafruit_BME280 bme;
Adafruit_SHT31 sht31 = Adafruit_SHT31();

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);
  if (!bme.begin(0x76)) { // спробувати 0x77 при невдачі
    Serial.println("BME280 не знайдено!");
  }
  if (!sht31.begin(0x44)) {
    Serial.println("SHT31 не знайдено!");
  }
  // Sea-level тиск для висоти:
  // bme.seaLevelForAltitude(150, bme.readPressure());
}

void loop() {
  Serial.printf("BME: T=%.2f P=%.1f H=%.1f | SHT31: T=%.2f H=%.1f\n",
    bme.readTemperature(), bme.readPressure() / 100.0, bme.readHumidity(),
    sht31.readTemperature(), sht31.readHumidity());
  delay(2000);
}
```

## Common issues

1. **not та I2C-адреса** → `Could not find sensor`. Сканувати шину (`i2cdetect` / `i2c.scan()`), verify SDO: GND = 0x76, VCC = 0x77.
2. **CSB висить in повітрі** → сенсор випадково переходить in SPI-режим. Підтягнути CSB до VCC at роботі per I2C.
3. **Немає pull-up on SDA/SCL** → шина зависає. Більшість модулів мають 4.7-10 кОм on борту; голі мікросхеми - ставити зовнішні.
4. **Самонагрів BME280** → температура завищена on 1-2 °C at частому опитуванні. Опитувати раз on 2-5 с, увімкнути sleep/forced mode.
5. **BMP280 замість BME280** → вологість завжди NaN/0. verify `chip_id` та маркування, обробити відсутність вологості in коді.
6. **Конденсат on SHT31** → вологість 100 % and «залипання». Увімкнути вбудований heater on 1-2 с for просушування.
7. **Довгі I2C-лінії (>1 м)** → NACK, пошкоджені дані. Знизити частоту до 50-100 кГц, використати екран, або перейти on SPI.
