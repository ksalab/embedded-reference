# BME680 / CCS811 / MH-Z19 / PMS5003 - air quality and CO2

![[assets/img/air-quality-scheme.png|500]]
*Fig. 1. Connecting air quality sensors to ESP32: BME680/CCS811 via I2C, MH-Z19/PMS5003 via UART.*

## Purpose

Група сенсорів якості повітря for дому, офісу, школи та вуличних станцій моніторингу. BME680 - температура/вологість/тиск + VOC (леткі органічні сполуки, індекс IAQ). CCS811 - eCO2/TVOC (розрахункові, not справжній CO2). MH-Z19B - справжній NDIR-сенсор CO2 (400-5000 ppm) per UART/PWM. PMS5003 - лазерний лічильник пилу PM1.0/PM2.5/PM10 per UART with вентилятором. Разом закривають повний AQI-вузол on ESP32.

> CCS811 вимагає прогріву 48 годин for стабільних показань! MH-Z19B - 3 хв після ввімкнення, PMS5003 - 30 с on розгін вентилятора.

### Застереження прогріву

| Сенсор | that відбувається | Правило |
| --- | --- | --- |
| CCS811 | MOX-елемент «вигоряє», baseline плаває | 48 год безперервної роботи at першому ввімкненні, далі 20 хв; зберігати baseline in NVS |
| BME680 | Гарячий дріт 300 °C, IAQ дрейфує перші хвилини | 30 хв прогріву + бібліотека BSEC for IAQ |
| MH-Z19B | Лампа ІЧ прогрівається | Ігнорувати перші 3 хв, ABC-калібрування раз on 24 год on свіжому повітрі |
| PMS5003 | Вентилятор виходить on оберти | Перші 30 с дані сміттєві; спати між вимірами (setMode passive) |

## Module pin legend

| Пін | Тип | Куди | Примітка |
| --- | --- | --- | --- |
| VCC (BME680/CCS811) | Живлення 3.3 in | 3V3 ESP32 | CCS811 строго 3.3 in, 5 in спалить! |
| VCC (MH-Z19/PMS5003) | Живлення 5 in | VIN 5V (USB) | from окремого стабілізатора at довгих лініях; струм до 150 мА |
| GND | Земля | GND ESP32 | Спільна for всіх чотирьох |
| SCL / SDA | I2C | GPIO22 / GPIO21 | BME680 + CCS811 on одній шині (адреси різні) |
| WAK (CCS811) | Вхід | GND | on землю for постійних вимірів; до GPIO for сну |
| RST / INT (CCS811) | Вихід переривання | GPIO (опційно) | Можна not підключати |
| Tx / Rx (MH-Z19, PMS5003) | UART | GPIO16/GPIO17, GPIO18/GPIO19 | via UART1/UART2; not плутати Tx→Rx хрест-навхрест |
| PWM (MH-Z19) | Вихід ШІМ | GPIO (опційно) | Альтернатива UART: 1004 мс період |
| SET / RESET (PMS5003) | Вхід керування | 3V3 / GPIO | SET=L - сон; RESET - перезапуск |

## Wiring diagram

| ESP32 | module | Примітка |
| --- | --- | --- |
| 3V3 | BME680 VCC, CCS811 VCC | Тільки 3.3 in for CCS811! |
| 5V (VIN/VU) | MH-Z19B VCC, PMS5003 VCC | from USB 5 in, конденсатор 470 мкФ поруч |
| GND | GND усіх модулів | Зірка, товстий провід for 5 in вузлів |
| GPIO22 | BME680 SCL, CCS811 SCL | Спільна шина I2C0 |
| GPIO21 | BME680 SDA, CCS811 SDA | Pull-up 4.7 кОм |
| GPIO17 (TX2) | MH-Z19 RX, PMS5003 RX | via UART2; хрест: TX ESP → RX сенсора |
| GPIO16 (RX2) | MH-Z19 TX, PMS5003 TX | Один UART on один сенсор! Розвести: MH-Z19 → UART1, PMS5003 → UART2 |
| GPIO18/19 | PMS5003 TX/RX (UART1) | Альтернатива at двох сенсорах одночасно |

### ASCII-схема

```text
        ESP32 DevKit
   +------------------+
   |  3V3  -> BME680 VCC, CCS811 VCC (3.3V!)
   |  5V   -> MH-Z19 VCC, PMS5003 VCC (5V!)
   |  GND  -> GND x4 (зірка)
   |  G22  -> BME680 SCL + CCS811 SCL
   |  G21  -> BME680 SDA + CCS811 SDA
   |  G17 TX2 -> MH-Z19 RX
   |  G16 RX2 <- MH-Z19 TX
   |  G18 TX1 -> PMS5003 RX
   |  G19 RX1 <- PMS5003 TX
   +------------------+
   I2C0: 0x76 (BME680), 0x5A (CCS811)
   UART1 9600: PMS5003 | UART2 9600: MH-Z19
```

## ESP-IDF code

```c
#include "driver/uart.h"
#include "esp_log.h"

#define UART_MHZ UART_NUM_2
#define UART_PMS UART_NUM_1
static const char *TAG = "air";

// MH-Z19B: команда читання CO2
static int mhz19_read_co2(void)
{
    uint8_t cmd[9] = {0xFF, 0x01, 0x86, 0, 0, 0, 0, 0, 0x79};
    uart_write_bytes(UART_MHZ, (char *)cmd, 9);
    uint8_t r[9] = {0};
    if (uart_read_bytes(UART_MHZ, r, 9, pdMS_TO_TICKS(500)) != 9) return -1;
    if (r[0] != 0xFF || r[1] != 0x86) return -1;
    uint8_t chk = 0;
    for (int i = 1; i < 8; i++) chk += r[i];
    if ((0xFF - chk + 1) != r[8]) return -1;
    return r[2] * 256 + r[3];
}

// PMS5003: пасивний кадр 32 байти, початок 0x42 0x4D
static bool pms_read(int *pm25, int *pm10)
{
    uint8_t b[32];
    if (uart_read_bytes(UART_PMS, b, 32, pdMS_TO_TICKS(1000)) != 32) return false;
    if (b[0] != 0x42 || b[1] != 0x4D) return false;
    *pm25 = (b[12] << 8) | b[13];
    *pm10 = (b[14] << 8) | b[15];
    return true;
}

void app_main(void)
{
    uart_config_t uc = {.baud_rate = 9600, .data_bits = UART_DATA_8_BITS,
        .parity = UART_PARITY_DISABLE, .stop_bits = UART_STOP_BITS_1,
        .flow_ctrl = UART_HW_FLOWCTRL_DISABLE};
    uart_param_config(UART_MHZ, &uc);
    uart_set_pin(UART_MHZ, 17, 16, -1, -1);
    uart_driver_install(UART_MHZ, 256, 0, 0, NULL, 0);
    uart_param_config(UART_PMS, &uc);
    uart_set_pin(UART_PMS, 18, 19, -1, -1);
    uart_driver_install(UART_PMS, 256, 0, 0, NULL, 0);
    // BME680/CCS811 ініціалізуються по I2C окремо (BSEC / ccs811 lib)
    for (;;) {
        int co2 = mhz19_read_co2();
        int pm25 = 0, pm10 = 0;
        pms_read(&pm25, &pm10);
        ESP_LOGI(TAG, "CO2=%d ppm  PM2.5=%d PM10=%d", co2, pm25, pm10);
        vTaskDelay(pdMS_TO_TICKS(5000));
    }
}
```

## Arduino code

```cpp
#include <Wire.h>
#include <Adafruit_CCS811.h>
#include <Adafruit_BME680.h>
#include <MHZ19.h>
#include <HardwareSerial.h>

Adafruit_CCS811 ccs;
Adafruit_BME680 bme;
MHZ19 mhz;
HardwareSerial pmsSerial(1); // UART1 для PMS5003
HardwareSerial mhzSerial(2); // UART2 для MH-Z19

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);
  if (!ccs.begin(0x5A)) Serial.println("CCS811 не знайдено! Прогрів 48 год!");
  // ccs.setDriveMode(CCS811_DRIVE_MODE_60SEC);
  if (!bme.begin(0x76)) Serial.println("BME680 не знайдено!");
  bme.setGasHeater(320, 150); // 320 C, 150 мс
  mhzSerial.begin(9600, SERIAL_8N1, 16, 17);
  mhz.begin(mhzSerial);
  mhz.autoCalibration(true); // ABC раз на 24 год
  pmsSerial.begin(9600, SERIAL_8N1, 19, 18);
}

void loop() {
  if (ccs.available() && !ccs.readData()) {
    Serial.printf("eCO2=%d TVOC=%d\n", ccs.geteCO2(), ccs.getTVOC());
  }
  Serial.printf("BME680 gas=%.0f Om\n", bme.readGas());
  Serial.printf("CO2=%d ppm\n", mhz.getCO2());
  // PMS5003: читати кадр 0x42 0x4D (див. ESP-IDF приклад)
  delay(5000);
}
```

## MicroPython code

```python
from machine import I2C, UART, Pin
import time

i2c = I2C(0, scl=Pin(22), sda=Pin(21))
print("I2C:", [hex(a) for a in i2c.scan()])  # 0x76 BME680, 0x5A CCS811

mhz = UART(2, 9600, tx=17, rx=16)
pms = UART(1, 9600, tx=18, rx=19)

def read_mhz19():
    mhz.write(bytes([0xFF, 0x01, 0x86, 0, 0, 0, 0, 0, 0x79]))
    time.sleep_ms(100)
    r = mhz.read(9)
    if r and len(r) == 9 and r[0] == 0xFF and r[1] == 0x86:
        return r[2] * 256 + r[3]
    return None

while True:
    print("CO2:", read_mhz19(), "ppm")
    if pms.any() >= 32:
        b = pms.read(32)
        if b[0] == 0x42 and b[1] == 0x4D:
            print("PM2.5:", (b[12] << 8) | b[13], "PM10:", (b[14] << 8) | b[15])
    time.sleep(5)
```

## Common issues

| № | error | Симптом | Рішення |
| --- | --- | --- | --- |
| 1 | CCS811 without прогріву 48 год | eCO2 400 або 8192, стрибає | Прогріти 48 год безперервно, зберігати baseline in NVS (`getBaseline/setBaseline`) |
| 2 | CCS811 живлять from 5 in | Мікросхема гріється, згорає | Тільки 3.3 in! verify перемичку on модулі |
| 3 | MH-Z19 живлять from 3V3 | Нулі або 5000 ppm постійно | Обовʼязково 5 in, струм ≥ 150 мА, спільний GND |
| 4 | Два UART-сенсори on одному UART | Кадри перемішуються | MH-Z19 → UART2, PMS5003 → UART1, швидкість 9600 in обох |
| 5 | PMS5003 without пауз | Вентилятор зношується for рік | Passive mode: спати (`0x42 0x4D 0xE4`), будити раз on 5-10 хв |
| 6 | BME680 without BSEC | «Газ» є, but IAQ немає | IAQ рахує лише бібліотека BSEC (закритий blob); сирий опір - not IAQ |
| 7 | ABC-калібрування in кімнаті | CO2 «повзе» до 400 вночі | Калібрувати on вулиці/свіжому повітрі або вимкнути ABC (`autoCalibration(false)`) and калібрувати вручну |
