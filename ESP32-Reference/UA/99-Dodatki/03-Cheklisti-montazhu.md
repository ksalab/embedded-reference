# Чек-листи монтажу та запуску

![[assets/img/placeholder.png]]

Процес: старт [[Home]], піни [[99-Dodatki/01-Pinout-tablici]], живлення [[02-Zhivlennya/01-Lancjugi-zhivlennya]] + [[13-Moduli-zhivlennya-rivniv/01-Buck-Boost-Solar]], рівні [[13-Moduli-zhivlennya-rivniv/02-Level-Shifters]], діагностика [[99-Dodatki/02-Troubleshooting-FAQ]], даташити [[99-Dodatki/04-Datasheet-Links]].

## 1. Перший запуск DevKit (5 хв)

- [ ] USB DATA-кабель (не charge-only), порт без хаба
- [ ] Драйвер CH340/CP2102 встановлено, COM-порт видно
- [ ] Нічого не підключено до GPIO0/2/5/12/15 (strapping вільні)
- [ ] Прошити Blink / Hello World на 115200, монітор 115200 8N1
- [ ] Кнопки EN+BOOT працюють: EN=reset, BOOT+EN=download
- [ ] 3.3V пін мультиметром: 3.20-3.40V, не гріється LDO
- [ ] WiFi-скан знаходить >3 мережі (антена жива)

## 2. Пайка та монтаж

- [ ] Флюс + температура 300-320 C, жало чисте, пайка блискуча конусом
- [ ] Немає перемичок між сусідніми пінами (перевірити лупою x10)
- [ ] Продзвонити: VCC-GND не коротять (>1к у зворотному), SDA/SCL не коротять на землю
- [ ] Розєми: спочатку гребінки, потім дроти; кольори: червоний VCC, чорний GND, жовтий/зелений сигнал
- [ ] Довжина I2C <30 см, SPI <20 см, UART <100 см (або вита пара)
- [ ] Pull-up I2C 4.7к, CS SPI 10к до 3.3V, EN 10к+10мкФ, BOOT 10к до 3.3V
- [ ] TVS + запобіжник на зовнішніх лініях (див. [[13-Moduli-zhivlennya-rivniv/02-Level-Shifters]])

## 3. Живлення (перед першим вмиканням!)

| ESP32 | Перевірка | Норма |
| --- | --- | --- |
| 5V VIN | напруга buck без навантаження | 5.00 +- 0.10V |
| 3.3V | напруга LDO без навантаження | 3.30 +- 0.10V |
| GND | опір до корпусу/землі | 0 Ом, немає петель |
| Струм холостий | USB-тестер без WiFi | 40-80 мА classic, 20-40 мА S3/C3 |
| Струм WiFi TX | скан мереж | пік 350-500 мА, просадка <0.15V |

- [ ] Buck виставлений БЕЗ ESP32, залитий лаком (див. [[13-Moduli-zhivlennya-rivniv/01-Buck-Boost-Solar]])
- [ ] SIM800L: 4.0V + 1000 мкФ, NRF24: 3.3V + 10 мкФ, камера: +100 мкФ
- [ ] RC522/LoRa тільки 3.3V, SIM800L тільки 4V - перевірити двічі!

## 4. I2C / SPI запуск

- [ ] I2C-сканер знаходить адресу (0x76/0x77 BME280, 0x68 MPU, 0x27 LCD)
- [ ] Частота стартова 50-100 кГц, потім 400 кГц якщо стабільно
- [ ] Логічний аналізатор / осцилограф: SDA/SCL фронти чисті, без сходинок
- [ ] SPI: почати з 1 МГц, CS togglиться, MISO не висить (pull-up 10к)
- [ ] RC522 DumpVersion не 0x00/0xFF; NRF24 printDetails показує конфіг

## 5. WiFi / Radio

- [ ] Скан: RSSI > -75 дБм на місці встановлення
- [ ] Підключення + ping роутера <50 мс, реконект при обриві реалізовано
- [ ] MQTT/HTTP: keepalive 15-30 с, таймаути, watchdog на зависання
- [ ] LoRa: частота відповідає напису на Ra-02 (433 vs 868), антена накручена ДО живлення
- [ ] NRF24: PA_LOW на столі, PA_MAX тільки з добрим живленням і відстанню

## 6. Deep-sleep замір

- [ ] Все зайве вимкено: USB-UART живлення в розрив, LED відпаяні або враховані
- [ ] Мультиметр/INA219 у розрив 5V: активний режим записаний, sleep записаний
- [ ] Норма classic: modem-sleep ~20 мА, light-sleep ~2 мА, deep-sleep 10-150 мкА (залежно від плати)
- [ ] Wakeup-джерела перевірені: timer + ext0/ext1 + touch, після wakeup периферія реініціалізована
- [ ] Батарейний розрахунок: 3000 мАг / середній струм = години; запас x1.5 на холод

## 7. Реліз-чек (перед віддачею/встановленням)

- [ ] Partition з OTA, версія прошивки в EEPROM/NVS, логування в Serial + файл
- [ ] WDT увімкнено, brownout 2.7V, код переживає reboot (стан у RTC/NVS)
- [ ] Корпус: вентиляція, антена назовні, дроти зафіксовані, вологозахист за потреби
- [ ] Документація: схема, pinout-лист, пароль WiFi, де лежить прошивка .bin
- [ ] Запасний модуль ESP32 + прошитий .bin на флешці поруч з виробом

## 8. Серійний чек (партія 10+ шт, перед відвантаженням!)

```text
[ ] Прошивка однакова: версія + sha на всіх (читати назад і звірити!)
[ ] NVS: серійники унікальні (mfg-партиція, не клон!)
[ ] eFuse: summary збережено в лог партії (див. 17-Lab/03)
[ ] Self-test PASS на кожній (див. 17-Lab/03 розд. 8)
[ ] RF: RSSI-вибірково проти еталона (3 шт з 10)
[ ] Корпус: вводи затягнуті, заглушки стоять, Gore на місці
[ ] Комплект: плата + антени + кріплення + папірець з QR на доку
```
