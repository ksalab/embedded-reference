## Детально

### 1. Дільник напруги

5V -> 1к (верх) + 2к (низ) = 3.33V. Для UART: 1к послідовно + стабілітрон 3.3V як альтернатива. Недолік: сповільнює фронти (RC з ємністю входу), їсть струм постійно. НЕ ставити на виходи ESP32 до 5V входів - там треба boost (див. нижче).

| ESP32 | Дільник | 5V-пристрій |
| --- | --- | --- |
| GPIO16 RX | вузол 1к/2к | TX 5V |
| GPIO17 TX | безпосередньо або через 74AHCT125 | RX 5V (якщо 5V вхід толерантний до 3.3V HIGH - часто працює безпосередньо) |

### 2. TXS0108E vs TXB0108

- TXB: для push-pull (SPI, UART). НЕ любить pull-up і відкритий колектор.
- TXS: для open-drain + push-pull (I2C + UART + SPI повільний). Має внутрішні 10к pull-up.
- Обидва: OE підтягнути до VCCA (3.3V) через 10к, VCCA=3.3V, VCCB=5V, земля спільна. Конденсатори 100 нФ біля обох живлень. Довжина доріжок мінімальна.

| ESP32 | TXS0108E | 5V-сторона |
| --- | --- | --- |
| 3V3 | VCCA | - |
| GND | GND | GND |
| GPIO21 SDA | A1 | B1 -> SDA 5V |
| GPIO22 SCL | A2 | B2 -> SCL 5V |
| 3V3 через 10к | OE | - |

### 3. I2C level-shift особливості

- I2C - open-drain, потрібен двонаправлений shift (MOSFET BSS138 або TXS0108E). Дільник ЗАБОРОНЕНО.
- Pull-up тільки з одного боку або слабкі з обох: загальний еквівалент 2-4.7к до відповідної напруги кожного боку. Занадто сильні pull-up (1к з обох) - шина не опуститься до LOW.
- Ємність шини < 400 пФ (до ~50 см дротів на 100 кГц). Довші - знижувати частоту до 50 кГц або I2C-екстендер P82B715.
- Див. [[04-Shini/03-I2C|I2C]].

### 4. PC817 опторозв'язка (коли потрібна гальваніка)

```text
24V датчик -> 2.2к -> LED PC817 (анод), катод -> GND24
Фототранзистор: колектор -> 3.3V через 10к (або GPIO з pull-up), емітер -> GND ESP32
GPIO читає інверсію: LED горить = GPIO LOW. Для швидкості додати 1к + прискорюючий конденсатор 100пФ паралельно вхідному резистору.
```

Швидкий варіант: 6N137 / PC900 (10 Мбіт) для ізольованих UART/SPI.

### 5. ESD та TVS захист

- Людські руки + довгі дроти = ESD. На всі зовнішні лінії (кнопки, I2C назовні, RS485): TVS-діоди PESD3V3 / PRTR5V0U2X + серійний резистор 47-100 Ом + конденсатор 100 пФ до землі.
- RS485/CAN: TVS SM712 (спеціальний для RS485) між A-B-GND. Ethernet: вбудовані трансформатори + TVS.
- Живлення: TVS SMBJ5.0A на вході 5V + самовідновлюваний запобіжник 1-2A.

| Симптом | Причина | Рішення |
| --- | --- | --- |
| I2C NACK через shift | TXB замість TXS / сильні pull-up | TXS0108E або BSS138, перевірити pull-up |
| 5V на GPIO, ESP32 гріється | прямий вхід 5V | дільник/shift, перевірити чи не пробито |
| Оптопара не бачить імпульси | повільний PC817 на 115200 | 6N137 або прямий shift без ізоляції |

## Схема підключення

| ESP32 | TXS0108E | 5V-сторона |
| --- | --- | --- |
| 3V3 | VCCA | - |
| GND | GND | GND (спільна!) |
| GPIO21 SDA | A1 | B1 → SDA 5V |
| GPIO22 SCL | A2 | B2 → SCL 5V |
| 3V3 через 10к | OE | - |

### ASCII-схема

```text
ESP32 (3.3 В)           TXS0108E (8 каналів)          5 В сенсор/шина
-------------           ------------------          ----------------
3V3 ──────────────────► VCCA (= 3.3 В)
5V ────────────────────────────────────────────────► VCCB (= 5 В)
GND ──────────────────► GND ◄────────────────────── GND (спільна!)
GPIO21 SDA ───────────► A1 ──► B1 ─────────────────► SDA 5V
GPIO22 SCL ───────────► A2 ──► B2 ─────────────────► SCL 5V
3V3 ──[10 кОм]────────► OE (HIGH = робота)
VCCA ◄──[100 нФ]──► GND; VCCB ◄──[100 нФ]──► GND (біля мікросхеми)
I2C — тільки TXS (не TXB!); дільник на I2C ЗАБОРОНЕНО
```

### NT0104 / SN74LVC2T45 - коли TXS замало

| Позиція | Що це | Нюанс |
| --- | --- | --- |
| NT0104 (Nexperia) | 4-бітний транслятор з напрямом по піну DIR | Передбачуваний напрям (на відміну від авто-TXS) - для UART RTS/CTS і SPI CS |
| SN74LVC2T45 | 2-бітний, до 420 Мбіт/с | Швидкі шини, де TXS «задихається» на фронтах |

```text
ESP32 GPIO ──► A-сторона ──[DIR=HIGH]──► B-сторона 5V-пристрій (і назад при DIR=LOW)
VCCA=3.3V, VCCB=5V, OE до VCCA через 10к (не залишати висячим!)
```

> Правило вибору: I2C/open-drain → TXS0108; UART/SPI з відомим напрямом → NT0104/SN74LVC2T45; одна лінія → BSS138/резистивний дільник.

### Одна лінія на BSS138 (коли TXS0108 - забагато)

```text
3.3V ──[10к]──┬── 3.3V-сторона (ESP32)
              │
            [BSS138: Gate→3.3V, Source→3.3V-сторона, Drain→5V-сторона]
              │
5V ───[10к]───┴── 5V-сторона (сенсор)
Двобічно для open-drain (I2C!) і повільних ліній; для SPI>10 МГц — TXB0104.
```

### TXS vs TXB vs дільник - швидка таблиця

| Варіант | Швидкість | Напрям | Коли |
| --- | --- | --- | --- |
| Дільник 1к/2к | до ~1 МГц | Вниз (5→3.3) | UART-TX, повільні сигнали |
| BSS138-канал | до ~2 МГц | Двобічно (open-drain) | I2C, 1-Wire |
| TXS0108 | до 24 МГц push-pull | Авто | SPI, швидкі шини |
| TXB0104 | до 100 МГц | Авто (без pull!) | Без підтяжок на лініях |
