## Reading

- **With Obsidian** (full experience: graph, backlinks, embeds): open any vault
  folder in [Obsidian](https://obsidian.md), start from `Home.md`
  (reading paths for beginners, map of all sections).
- **Right here on GitHub** (no install): the same content converted to plain
  Markdown links lives in [`docs/`](docs/) — callouts, mermaid diagrams and
  code render natively. `docs/` is generated by [`tools/export_github.py`](tools/export_github.py) —
  never edit it by hand, edit the vaults and re-run the script.

## Note standard

- YAML frontmatter (`title`, `description`, `tags`, `category`, `date-created`, `date`);
- figure `![[assets/img/…|600]]` + italic caption;
- mermaid diagram; code (Arduino / ESP-IDF / MicroPython where relevant);
- error table (`Symptom → Cause → Fix`); «Official sources» section with links
  to the exact model/manufacturer documentation (guessed URLs forbidden);
- ≥150 lines.

## Checks

Each vault has `scripts/`:

```bash
python3 scripts/check_style.py   # note standard, expect violations=0
python3 scripts/check_links.py   # [[link]] and PNG validity, broken=0
python3 scripts/check_home.py    # Home counters and navigation coverage, home-errors=0
```

Lint from the repo root ([.markdownlint.yaml](.markdownlint.yaml)):

```bash
markdownlint "ESP32-Reference/**/*.md" "STM32-Reference/**/*.md" \
  "ARDUINO-Reference/**/*.md" "RaspberryPi-Reference/**/*.md"
```
