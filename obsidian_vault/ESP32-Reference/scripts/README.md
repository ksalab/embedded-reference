# scripts/ - допоміжні скрипти бази

Ця папка містить усі службові скрипти, якими генерується та перевіряється
Obsidian-база `ESP32-Reference`. Запускати з кореня vault.

| Скрипт | Призначення | Запуск |
| --- | --- | --- |
| `generate_schemes.py` | Генерує wiring/pinout PNG у `assets/img/` (PIL + DejaVu, єдиний стиль: шапка + булети + смуга 3.3V + футер). Ніяких копійованих картинок - чиста ліцензія. Кількість росте з базою (станом на v0.19 - 166 записів). | `python3 scripts/generate_schemes.py` |
| `check_links.py` | Перевіряє всі вікіпосилання між нотатками (мають вести на існуючі файли) та всі `assets/img/*.png` (мають існувати). Вихід 0 - чисто. УВАГА: парсить навіть текст у бектиках - не писати буквальні вікіпосилання й імена неіснуючих PNG в TODO/коментарях/прикладах! | `python3 scripts/check_links.py` |
| `check_style.py` | Перевіряє ЄДИНИЙ ФОРМАТ нот: frontmatter (title/description/tags/category/date), рисунок, mermaid, секція помилок, джерела, ≥150 рядків, title↔H1 (спільний токен 3+), чисті скрипти (без CJK; µΩ° - легітимні!), цілий `\|` у вікілінках, без гомогліфів, без транслітерованих аліасів (`bad-alias`: аліас == імені файла - ознака автогенерації; писати українські короткі аліаси або голі посилання без аліаса) (ekerан, тu, пH - лагодити; ROMів, Vвх, Tсимволу, MQTT-топологія - легітимні винятки, див. код). | `python3 scripts/check_style.py` |
| `check_home.py` | Перевіряє Home-навігацію: лічильники `(N нот)` збігаються з файлами в папках; кожна контентна нота згадана в Home. | `python3 scripts/check_home.py` |
| `comp_inventory.py` | Інвентаризація компонентів: токени-моделі з тіл нот (без коду, мінус піни/периферія/AT/appnotes) + класифікація посилань «Офіційних джерел» (виробники vs інші). Режими `--json` і `--registry COMPONENTS.md` (генерація реєстру; файл автогенерований, поза валідаторами!). Інформаційний, exit завжди 0. | `python3 scripts/comp_inventory.py [--json out.json] [--registry COMPONENTS.md]` |

Залежності: Python 3 + Pillow (`pip install pillow`).

## Як додати нову схему (покроково!)

1. Відкрити `generate_schemes.py`, знайти словник `C = {...}` (починається після `fonts()`).
2. Додати запис ВСЕРЕДИНУ словника (перед закриваючою дужкою - НЕ після функції малювання!; приклад нижче умовний, реальні записи дивитись у самому файлі):

   ```python
   "bme280-i2c.png": ("BME280 — I2C 0x76/0x77",
    ["3V3 ──► VIN   GND ─── GND",
     "GPIO22 ──► SCL + pull-up 4.7к"]),
   ```

3. Правила запису: ім'я - малі літери + дефіси + `-scheme.png`; рядків 5-9; українська; стрілки `──►`/`◄──`; БЕЗ бектиків і вікіпосилань у подвійних дужках у текстах (зламають PNG і чекер).
4. Запустити `python3 scripts/generate_schemes.py` → перевірити `generated N png` (N зросло!).
5. Відкрити PNG і глянути очима: заголовок не обрізаний (ліміт ~45 символів при 40pt!), булети читабельні.
6. Вставити в ноту: ембед-картинка на свій PNG з `assets/img/` шириною 600 + підпис курсивом `Рис. ...` (формат - подвійні квадратні дужки як у решти нот, НЕ одинарні і НЕ в бектиках!).
7. Додати рядок у таблицю `assets/README.md` (наступний номер + нота + що видно) та ім'я у список зайнятих.
8. Запустити `python3 scripts/check_links.py` → `broken=0`, `missing=NONE`.

## Формат AT-шпаргалок (єдиний!)

Таблиця 4 колонки: `| Команда | Відповідь OK | Що означає | Типова помилка |`.
Послідовності з порядком (SAPBR, HTTP) - текстовими блоками `CMD -> відповідь` з коментарями.
Зведені шпаргалки: SIM800 - нота 03, 4G - нота 07, повна 35 команд - нота 18; усі три перехресно посилаються.
