## [v0.13] - 2026-10-06 - широта-2: світло/тиск/ToF, струм, CO2, BT/Ethernet, індикація, флагмани, HTTP, рідкісні сенсори

### Додано

- `10-Sensori/09-Svitlo-Tisk-ToF.md` (162 рядки): BH1750, BMP280, VL53L0X на одній шині, код, калібрування.
- `10-Sensori/10-Strum-INA219.md` (175 рядків): INA219 + ACS712, облік ампер-годин з EEPROM.
- `10-Sensori/11-CO2-Povitrya.md` (152 рядки): MH-Z19B NDIR + BME680, пороги, гістерезис.
- `12-Moduli-zvyazku/05-BT-Ethernet.md` (167 рядків): HC-05 термінал + W5100 веб-сервер в одному скетчі.
- `11-Vivid/06-Indikatsiya-Audio.md` (з біжучим рядком): MAX7219, TM1637, DFPlayer з кодом.
- `14-Devboards/03-Nano-ESP32-GIGA.md` (зі струмами): Nano ESP32 + GIGA R1, `#ifdef` на обидві.
- `15-Protokoli/03-HTTP-Web.md` (170 рядків): GET/POST вручну, вебхуки, HTTPS-межі.
- `10-Sensori/12-Mag-Gesture-RTC.md` (169 рядків): QMC5883L, APDS-9960, DS3231, зв'язка з GPS.
- 8 PNG-схем + лінки і лічильники в `Home.md` (сенсори 12, вивід 6, зв'язок 5, плати 3, протоколи 3).

- Перевірка: style 0 / links 0 (75 файлів / 574 посилання) / home 0, PNG 71/71, реєстр 89/89.
