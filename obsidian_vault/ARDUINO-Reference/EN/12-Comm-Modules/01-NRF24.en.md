# NRF24L01 - Radio over SPI

![[assets/img/arduino-nrf24-scheme.png|600]]
*Fig. Radio module on board, power through stabilizer, capacitor on power bus and channels.*

> [!tip] Purpose of this note
> Explain cheap radio between two boards: how to power the module, how to choose a channel away from home network and how to start a transmitter-receiver pair.

## 1. Purpose

The module gives a simple exchange channel between boards without wires over room or floor distance.

The main board controls the module through fast bus, and the module itself works in open-band air.

A pair of modules replaces a long cable between a room sensor and receiver near the computer.

The module is cheap, library open, many examples, so start is quick.

Honest limit: short telemetry and command packets, not streaming video or sound.

This note covers base: power, connection, library, addresses, channels and two working sketches.

Fast bus basics see in the note [[EN/04-Interfaces/02-SPI.en|Fast bus]].

Classic board for first experiments described in the note [[EN/01-Hardware/01-AVR-Uno.en|Classic AVR]] (if unavailable link as-is with note).

## 2. What the module can do

| Parameter | Value | Practical meaning |
| --- | --- | --- |
| Band | Open band around 2.4 GHz | No license, but together with home networks |
| Channels | One hundred twenty-six steps by one megahertz | Room to escape noise |
| Air speed | 250 kbps, 1 or 2 Mbps | Slower means farther and more stable |
| Packet | Up to 32 bytes payload | Short commands and sensor readings |
| Power | 3.3 V | Five volts burns the module |
| Control | Fast bus plus two separate signals | One chip select and one transmit enable |
| Price | Cheapest way to link two boards | For experiments take a pair at once |

The module exists in two versions: small with printed antenna and large with amplifier and external antenna.

Small version fits a room; large with antenna pulls through walls and to yard.

Both versions are controlled the same; difference only in range and current appetite.

For first experiment take two small versions and place them a couple meters apart.

```text
Module variants:

  Small:
  printed antenna on board
  range ~30 m indoor

  Large with PA and antenna:
  external antenna connector
  range ~100 m open
```

## 3. Power and capacitor

| Source | Voltage | Note |
| --- | --- | --- |
| Board 3.3 V | Exact | Best, stable |
| Board 5 V through regulator | If module lacks regulator | Many modules need 3.3 V only |

A capacitor near one hundred microfarads across power lines smooths current spikes during transmission.

Ground is common for all modules and board.

## 4. Connection and bus

| Module pin | Board pin | Note |
| --- | --- | --- |
| CE | Any digital | Chip enable |
| CSN | Any digital | Chip select |
| MOSI | MOSI | Data to module |
| MISO | MISO | Data from module |
| SCK | SCK | Clock |
| IRQ | Any digital (optional) | Interrupt on packet |
| VCC | 3.3 V | Never five |
| GND | GND | Common |

The module uses SPI; CSN and CE are separate for control.

## 5. Library RF24

Install RF24 by TMRh20 through library manager.

```cpp
#include <SPI.h>
#include <RF24.h>
RF24 radio(9, 10); // CE, CSN
void setup() { radio.begin(); radio.openWritingPipe(0xF0F0F0F0E1LL); radio.openReadingPipe(1, 0xF0F0F0F0D2LL); radio.setPALevel(RF24_PA_LOW); }
void loop() {}
```

Address is 5 bytes; choose unique for pair.

## 6. Channel and noise

| Channel | Use when |
| --- | --- |
| 76 | Near WiFi channel 1 |
| 100 | Middle, less crowded |
| 125 | Far from home band |

Scan channels with simple code to find quiet ones.

## 7. Sketch transmitter

```cpp
#include <SPI.h>
#include <RF24.h>
RF24 radio(9,10);
void setup() { radio.begin(); radio.openWritingPipe(0xF0F0F0F0E1LL); radio.setPALevel(RF24_PA_LOW); }
void loop() { int val = analogRead(A0); radio.write(&val,sizeof(val)); delay(100); }
```

## 8. Sketch receiver

```cpp
#include <SPI.h>
#include <RF24.h>
RF24 radio(9,10);
void setup() { radio.begin(); radio.openReadingPipe(1,0xF0F0F0F0D2LL); radio.setPALevel(RF24_PA_LOW); radio.startListening(); }
void loop() { if (radio.available()) { int val; radio.read(&val,sizeof(val)); } }
```

## 9. Common issues

| # | Issue | Fix |
| --- | --- | --- |
| 1 | No connection | Check CE/CSN, power 3.3 V |
| 2 | Wrong address | Set same pipe pair |
| 3 | No response | Check channel away from WiFi |
| 4 | Short range | Use PA version, lower speed |
