# ESP32 Reference - головна карта довідника

EN version: `Home.en.md`

> [!tip] Навігація
> Це MOC всього довідника. Старт: [Як користуватись](../../ESP32-Reference/00-Start/01-Yak-koristuvatis-dovidnikom.md) → [Порівняння чипів](../../ESP32-Reference/00-Start/03-Porivnyannya-chipiv.md) → [DevKit плати](../../ESP32-Reference/00-Start/04-Devkit-plati.md) → [Вибір середовища](../../ESP32-Reference/00-Start/05-Vibir-seredovischa.md).

Довідник покриває ESP32 / S2 / S3 / C3 / C6 / H2: вибір чипа, живлення, GPIO, шини, радіо, сон, пам'ять, прошивка, сенсори, вивід, модулі зв'язку. Приклади скрізь у 3 стеках: ESP-IDF + Arduino + MicroPython. Вся логіка - **3.3V**.

> [!warning] Живлення 3.3V!
> ESP32 **не толерантний до 5V** на GPIO. Див. [Рівні 3.3V/5V](../../ESP32-Reference/03-GPIO/03-Pidtyaguvannya-rivni.md) та [Level-shifters](../../ESP32-Reference/13-Moduli-zhivlennya-rivniv/02-Level-Shifters.md).
