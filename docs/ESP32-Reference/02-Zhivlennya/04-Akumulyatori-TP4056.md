# Акумулятори та TP4056

![](../../../ESP32-Reference/assets/img/placeholder.png)

> [!warning] ESP32 - тільки 3.3V, не 4.2V!
> Повністю заряджений LiPo - 4.2V, це забагато для ESP32 (**3.3V** макс 3.6V). Завжди став LDO або buck між акумулятором і ESP32.

## Призначення

Акумулятори та TP4056 - Ланцюг; Схема ESP32+TP4056+buck; Таблиця з'єднань ESP32|Модуль. Повністю заряджений LiPo - 4.2V, це забагато для ESP32 (3.3V макс 3.6V). Завжди став LDO або buck між акумулятором і ESP32. TP4056 без NTC не знає температури акума. Додай контроль сам - інакше заряд за низької/високої температури вб'є акум.

## Ланцюг

| Вузол | Напруга | Примітка |
| --- | --- | --- |
| 18650 / LiPo | 3.0-4.2V | Номінал 3.7V |
| TP4056 OUT | 3.0-4.2V | Зарядка + захист DW01 |
| Buck/LDO | **3.3V** | Тільки потім на ESP32 |
| ESP32 3V3 | **3.3V** | Пік 500 мА WiFi |

> [!danger] Чому не живити від 5V піна TP4056 без LDO
> На платах TP4056 пін OUT - це НЕ стабільні 5V і НЕ **3.3V**, а пряма напруга батареї 3.0-4.2V плюс просадки. Без стабілізатора отримаєш перезавантаження і смерть flash. Обов'язково buck/LDO на **3.3V**. Див. [01-Lancjugi-zhivlennya](../../../ESP32-Reference/02-Zhivlennya/01-Lancjugi-zhivlennya.md), [02-LDO-DC-DC](../../../ESP32-Reference/02-Zhivlennya/02-LDO-DC-DC.md).

## Схема ESP32+TP4056+buck

| З'єднання | Куди |
| --- | --- |
| B+ / B- TP4056 | Акумулятор 18650 |
| OUT+ TP4056 | Buck IN+ |
| OUT- TP4056 | Buck GND + ESP32 GND |
| Buck OUT 3.3V | ESP32 3V3 (**3.3V** рівно) |
| Solar 5-6V | TP4056 IN+ (через діод) |

> [!tip] Solar
> Панель 5V 1-2 Вт через діод Шотткі на TP4056 IN. Струм заряду вистав резистором Rprog (1.2 кОм = 1A, для 18650 краще 0.5A). Споживання вузла рахуй за [03-Spozhivannya](../../../ESP32-Reference/02-Zhivlennya/03-Spozhivannya.md). Дільник контролю батареї - на ADC тільки 0-3.3V, див. [01-GPIO-oglyad](../../../ESP32-Reference/03-GPIO/01-GPIO-oglyad.md).

## Ємність vs реальність (правило 0.2C)

Напис «3000 мАг» на акумуляторі - це при розряді 0.2C (600 мА для 3000 мАг) до 3.0V при 25°C. ESP32 з WiFi-TX дає імпульси 500 мА + холод + старий акумулятор = мінус 30-50%.

| Умова | Реальна віддача від номіналу | Пояснення |
| --- | --- | --- |
| Розряд 0.2C, 25°C, новий | 95-100% | Еталон даташиту |
| Імпульси 0.5-1C (WiFi-TX) | 80-90% | Внутрішній опір зʼїдає напругу |
| Холод +5°C | 80% | Хімія сповільнюється |
| Холод −10°C | 50-60% | + ризик мідних дендритів при заряді! |
| Спека +45°C | 95%, але старіння ×2 | Календарне старіння прискорюється |
| 300 циклів / 2 роки | 70-80% | Ємність тане навіть на полиці |
| NoName «9900 мАг» 18650 | 800-1200 мАг реально | Фізика: більше 3500 мАг в 18650 не буває! |
| 21700 (наступник 18650) | 4000-5000 мАг, той же Li-ion | Більший струм і ресурс; тримач/холдер - тільки під 21700, в 18650-відсік не влізе |

Розрахунок робочого часу з поправкою:

```text
T = Cном × k_реаль × k_темп × k_вік / Iсер

Приклад: 18650 2600 мАг, Iсер 50 мА (сенсор + modem-sleep), вулиця +5°C, акуму 1 рік:
T = 2600 × 0.85 × 0.8 × 0.9 / 50 ≈ 32 год.
Той самий вузол в кімнаті з новим акумом: 2600 × 1.0 / 50 = 52 год.
Різниця ×1.6 — закладай у ТЗ одразу!
```

> [!warning] Пульсуюче навантаження і захист DW01
> Плата захисту вимкає акум при ~2.4-3.0V (залежно від DW01-клона). Імпульс TX 500 мА на підсівшому акумі короткочасно садить напругу нижче порога → захист відрубає живлення → вічний цикл «старт-ребут». Лікування: свіжий акум + 470 мкФ на 3.3V + поріг deep-sleep вище (засинай при 3.4V, а не при 3.1V).

## Саморозряд

| Хімія | Саморозряд | Наслідок для ESP-вузла |
| --- | --- | --- |
| Li-ion 18650 (з захистом) | 2-5% / міс + плата захисту ~10 мкА | За півроку на полиці −30%. Перед сезоном - перезарядити! |
| LiPo пакет | 3-8% / міс | Мʼякий пакет + саморозряд = перевіряй здуття щосезону |
| LiFePO4 | 1-3% / міс | Найкращий для вулиці, але 3.2V номінал - перевір dropout LDO! |
| NiMH | 15-30% / міс | Для ESP не годяться взагалі |

## Термоконтроль NTC (10 кОм B=3950)

TP4056 без NTC не знає температури акума. Додай контроль сам - інакше заряд за низької/високої температури вб'є акум.

| Схема | Підключення | Пороги |
| --- | --- | --- |
| NTC 10к до акума (термопаста/скотч) + дільник 10к до 3.3V | Середина дільника → GPIO34 (ADC, 0-3.3V!) | R/R25 → температура за B-рівнянням |
| Поріг фейлу | ADC < 0.3V або > 3.0V | Обрив/КЗ датчика - заборонити заряд! |

```cpp
// NTC-контроль перед дозволом заряду (Arduino)
#define NTC_PIN 34
float ntc_temp() {
  int raw = analogRead(NTC_PIN);                 // 0–4095
  float v = raw * 3.3 / 4095.0;
  float r = 10000.0 * v / (3.3 - v);             // верхнє плече 10к до 3.3V
  float t = 1.0 / (1.0/298.15 + log(r/10000.0)/3950.0) - 273.15;
  return t;
}
bool charge_allowed() {
  float t = ntc_temp();
  return (t > 0.5 && t < 45.0);  // вікно заряду, див. нижче
}
void loop() {
  if (!charge_allowed()) {
    // Вимкни ключ заряду (MOSFET на IN+ TP4056) + спи до потепління
    Serial.printf("T=%.1f C — заряд ЗАБОРОНЕНО\n", ntc_temp());
  }
  delay(5000);
}
```

АЦП і рівні: [ADC](../../../ESP32-Reference/06-Analog/01-ADC.md), [03-Pidtyaguvannya-rivni](../../../ESP32-Reference/03-GPIO/03-Pidtyaguvannya-rivni.md).

## Заряд на морозі ЗАБОРОНЕНО + спека

| Температура акума | Заряд | Розряд | Чому |
| --- | --- | --- | --- |
| < 0°C | ЗАБОРОНЕНО (літій осідає металом → дендрити → КЗ) | Дозволено, але ємність −20…-50% | Занеси в тепло або грій бокс |
| 0…+5°C | Тільки 0.1C і під наглядом | Дозволено | Краще почекати тепла |
| +5…+45°C | Норма (0.5C для 18650, 1C макс) | Норма | Штатне вікно |
| > +45°C | Зупинити (деградація ×2-4) | Знизити навантаження | Тінь/вентиляція |
| > +60°C | Аварія (ризик розгерметизації) | Вимкнути | Віднести в тінь, не поливати холодною водою! |

> [!danger] Вуличний solar-вузол взимку
> Панель взимку дає струм → TP4056 заряджає крижаний акум → навесні акум здутий/мертвий. Рішення: NTC-ключ розриває IN+ TP4056 при T<+2°C (гістерезис 2-5°C), вузол живе з акума і чекає тепла. Сонячні нюанси: [01-Buck-Boost-Solar](../../../ESP32-Reference/13-Moduli-zhivlennya-rivniv/01-Buck-Boost-Solar.md), [03-TP4056-IP5306-BMS-UPS](../../../ESP32-Reference/13-Moduli-zhivlennya-rivniv/03-TP4056-IP5306-BMS-UPS.md).

## Паралельне зʼєднання: умови

| Правило | Значення | Чому |
| --- | --- | --- |
| Тільки однакові (модель, вік, ємність ±5%) | Наприклад, 2× Samsung 26H нові | Різні - сильний заряджає слабкого великим струмом |
| Перед зʼєднанням - вирівняти напругу до ±0.05V | Заряди обидва до 4.15V окремо | Інакше іскра і струм 5-10 А в момент спайки! |
| Кожен акум - зі своїм захистом DW01 | Або загальний BMS 2S/2P | Один голий акум у паралелі = пожежний ризик |
| Дроти однакової довжини/перерізу | Різниця < 5% опору | Інакше один працює за двох |
| Термоконтроль - на кожен пакет | NTC на кожен | Один гарячий - вимкай увесь блок |
| Послідовно (2S 7.4V) - тільки з BMS балансуванням | Ні в якому разі без BMS! | Без балансу один перезарядиться до 4.5V → займання |

```text
Правильна паралель 2×18650 для ESP-вузла:
[18650 #1 + DW01] ─┬─► OUT+ ──► buck/LDO ──► 3V3 ESP32
[18650 #2 + DW01] ─┘      (зʼєднання ПІСЛЯ плат захисту, не до банок!)
                   └─► OUT- ──► GND (зірка!)
Ємність подвоюється (5200 мАг), струм ділиться навпіл → менше просадок TX.
```

Дільник контролю батареї (0-3.3V на ADC!): два R по 100к, серединка на GPIO34, паралельно нижньому - 100nF. Вмикай через MOSFET, інакше +16 мкА цілодобово. Режими сну для економії: [03-Sleep-ULP](../../../ESP32-Reference/07-Timeri-Son/03-Sleep-ULP.md), вимір струму: [03-Spozhivannya](../../../ESP32-Reference/02-Zhivlennya/03-Spozhivannya.md).
