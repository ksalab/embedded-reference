# ESP32 Reference - reference home map

> [!tip] Navigation
> This is the MOC of the whole reference. Start: [How to use it](../../ESP32-Reference/00-Start/01-Yak-koristuvatis-dovidnikom.md) → [Chip comparison](../../ESP32-Reference/00-Start/03-Porivnyannya-chipiv.md) → [DevKit boards](../../ESP32-Reference/00-Start/04-Devkit-plati.md) → [Environment choice](../../ESP32-Reference/00-Start/05-Vibir-seredovischa.md).

The reference covers ESP32 / S2 / S3 / C3 / C6 / H2: chip choice, power, GPIO, buses, radio, sleep, memory, firmware, sensors, outputs, comms modules. Examples everywhere use 3 stacks: ESP-IDF + Arduino + MicroPython. All logic is **3.3V**.

> [!warning] 3.3V power!
> The ESP32 is **not 5V tolerant** on GPIO. See [3.3V/5V levels](../../ESP32-Reference/03-GPIO/03-Pidtyaguvannya-rivni.md) and [Level-shifters](../../ESP32-Reference/13-Moduli-zhivlennya-rivniv/02-Level-Shifters.md).
