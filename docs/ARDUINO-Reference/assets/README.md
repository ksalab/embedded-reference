# Assets - як додавати картинки

Картинки лежать у `assets/img/`, вставляються вікілінком `![](../../../ARDUINO-Reference/assets/img/<name>.png)`
з підписом курсивом. Генеруються скриптом `scripts/generate_schemes.py`
(записи - словник `C`, стиль: HAT-плата + булети + футер).
