# Діагностична карта RaspberryPi-Reference - симптом, прилад, дія

## Живлення

| Симптом | Прилад | Дія |
| --- | --- | --- |
| Блискавка / ребути | USB-тестер, `get_throttled` | БЖ + кабель |
| Гріється БЖ | рука / пірометр | запас струму 30 % |
| USB відвалюється | USB-тестер у розриві | хаб з живленням |

## Завантаження

| Симптом | Прилад | Дія |
| --- | --- | --- |
| ACT 4/7/8 спалахів | очі + таблиця кодів | перепрошити носій |
| Веселка висить | монітор | правити config.txt на ПК |
| Мовчить усе | UART-консоль | дивитись лог boot |

## GPIO і шини

| Симптом | Прилад | Дія |
| --- | --- | --- |
| Датчик мовчить | `i2cdetect` → аналізатор | шина, адреса, живлення |
| Кнопка стрибає | лог подій | bounce_time |
| Пін мертвий | мультиметр | переїхати, поставити перетворювач рівнів |

## Мережа

| Симптом | Причина | Дія |
| --- | --- | --- |
| Немає 5 ГГц | країна | raspi-config |
| Рветься щогодини | PM | вимкнути, watchdog |
| Повільно | канал/сигнал | сканер, провід |
